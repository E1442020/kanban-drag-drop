# Kanban Drag & Drop Application

This project is a Kanban board application built using JavaScript. It allows users to create tasks, categorize them into columns, and drag and drop tasks between columns to update their status.

## Usage

Once the development server is running, you can access the Kanban board application via your web browser. The application includes the following main functionalities:

Create Tasks: Add new tasks to the board.
Categorize Tasks: Place tasks into columns such as "To Do", "In Progress", and "Done".
Drag & Drop: Move tasks between columns using drag-and-drop functionality.
Edit Tasks: Modify the details of existing tasks.
Delete Tasks: Remove tasks from the board.
Example Usage
Open the application at http://localhost:3000.
Add tasks by clicking the "Add Task" button and filling out the form.
Drag and drop tasks between columns to update their status.
Edit a task by clicking the "Edit" button on a task.
Delete a task by clicking the "Delete" button on a task.

## Features

User-friendly Interface: Simple and intuitive interface for managing tasks on a Kanban board.
Drag & Drop: Easily move tasks between columns with drag-and-drop functionality.
Real-time Updates: See changes immediately as you add, edit, or move tasks.
Responsive Design: Works on desktops, tablets, and mobile devices.

## Technologies

This project is built using the following technologies:

JavaScript: Core language for building the application.
HTML5: Structure the web application.
CSS3: Style the web application.
Drag and Drop API: Native HTML5 drag-and-drop functionality.
